# AI News Tracker

## 1. Project Overview

AI News Tracker is a personal software engineering project focused on collecting, storing and analysing AI and technology news.

The application will retrieve news articles from a public API, process the returned JSON data and store relevant article information in an SQLite database.

SQL queries will be used to retrieve and explore the collected data.

Future development will introduce AI-powered features such as topic classification, sentiment analysis and article summarisation.

## 2. Project Objectives

- Retrieve news articles using a REST API.
- Process JSON responses using Python.
- Store article information in an SQLite database.
- Use SQL to filter, sort and analyse news articles.
- Explore AI-powered news classification and summarisation.
- Document the development process and technical decisions.

## 4. Data Source

**Hacker News Algolia Search API**

Base endpoint:

`https://hn.algolia.com/api/v1/search`

The initial implementation will retrieve AI-related stories using query parameters.
