# Development Log — AI News Tracker

This document records the development progress, technical decisions, challenges and lessons learned while building AI News Tracker.

---

## Project Initialization

**Date:** 11 November 2026

**Status:** Completed

### Objective
Set up the project workspace and establish the initial project documentation before beginning implementation.

### Completed tasks
- Created the `ai-news-tracker` project folder.
- Created the initial `README.md`.
- Defined the project objectives.
- Identified the planned technology stack.
- Established the initial development roadmap.

### Technologies identified
- Python
- REST APIs
- JSON
- Postman
- SQLite
- SQL
- Git and GitHub

### Technical decisions
1. Use the Hacker News Algolia Search API as the initial news source.
2. Test API requests in Postman before implementing them in Python.
3. Use SQLite for local data storage.
4. Introduce AI analysis after the basic data collection and storage pipeline works.

### Challenges
No technical challenges encountered during project initialization.

### What I learned
A software project benefits from having a defined purpose, development plan and documentation structure before implementation begins.

### Next milestone
**Milestone 1 — API Exploration and Testing**

The goal is to send a GET request to the Hacker News API using Postman, inspect the JSON response and identify the article fields needed by the application.
